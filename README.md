<h3 align="center">How I evaluate</h3>

<div align="center">

A score that only exists on a validation set is not a result. I measure out of sample and report
accuracy next to coverage, and when a model is not confident I would rather it abstain than guess.
A confident wrong answer costs more than no answer.

</div>
