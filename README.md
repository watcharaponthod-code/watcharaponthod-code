## About

I build AI systems that survive contact with the real world.

Most of my work sits in two places: **computer vision** — detection, pose, OCR, face
liveness, video pipelines running on live camera feeds — and **LLM systems** — RAG,
agents, tool use, structured output, local models. I take both the full distance: model,
API, app, deployment. I have shipped mobile apps, web dashboards, inference servers and
training pipelines, so the model does not stop at a notebook.

The part I care about most is honesty in evaluation. A number that only exists on a
validation set is not a result. I measure out-of-sample, report accuracy together with
coverage, and build models that decline to answer when they should — a wrong prediction
delivered confidently costs more than an abstention.
